# Цели Foldfin

Foldfin — экспериментальный VPN общего назначения с двумя режимами: TCP proxy
через SOCKS5 и IP VPN через TUN. Режим не зависит от транспорта: H2/rustls или
опциональный H3/Quinn. IP VPN переносит IPv4/IPv6, TCP/UDP/ICMP и допускает явно
разрешённые routed networks. CONNECT-UDP proxy остаётся отдельной незавершённой
функцией.

Один library crate предоставляет client/server API без собственного runtime,
учётной базы, issuer сертификатов или настройки сети ОС. CLI и Floppa используют
эту библиотеку как host-приложения. Chromium stack удалён.

Ближайший приоритет — завершить серверный путь Floppa: выдача конфигурации,
синхронизация прав устройств, общий TUN, изоляция клиентов, обновление сертификатов
и управляемый lifecycle. Критерии готовности и findings:
[SERVER-REVIEW.md](SERVER-REVIEW.md).

Затем завершить full/split routing и DNS lifecycle на клиенте и проверить связку
API/database/node/client. Проверки на ноутбуке в namespaces предшествуют physical
Android acceptance. Удалённые проверки выполняются только на Сингапуре через
физический интерфейс, без fallback через другой VPN.

Скрытность не является доказанным свойством. TLS/HTTP CONNECT отличается от
браузерного использования HTTPS; H2 имеет head-of-line blocking, H3 зависит от
доступности UDP и path MTU. Изменения транспорта оцениваются измерениями, а не
обещаниями универсального обхода блокировок.
